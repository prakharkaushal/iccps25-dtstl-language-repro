# Deviations, approximations and implementation decisions

This file lists every place where the implementation departs from the paper, approximates something it
relied on, or fills a gap it leaves open. Each entry gives what the paper says, what we do, why, and the
expected effect. IDs (A*, B*, D*) are referenced from the code, the configs and the result tables.
Paper = `Paper.pdf` (Abou-Mrad et al., ICCPS '25). Analysis = [docs/TARGET_ANALYSIS.md](docs/TARGET_ANALYSIS.md).

## A. Resources the paper used that are unavailable here

[5], `github.com/Chris-amV/FindBox`) | **Exact** language: NNF → unroll temporal operators → DNF of boxes → drop empty/contained boxes (`src/langfal/language.py`) | FindBox has no license and its use was not approved; for these 1-D formulas the exact union of boxes (Thm 2.3/Cor 2.4) is cheap (1–13 ms per formula, Table 1 extras) | (i) language monitor = RTAMT robustness exactly → Table 1 value agreement 100 % (paper 42.6 % for φ2/φ4); (ii) box counts of L(¬φ) are 11/8/27/27/7 (paper 7/3/85/2/7) → PROF/PBO run different numbers of processes; (iii) **many exact boxes are unreachable by the CC model** (e.g. "x(0) > 40" while x(0) = 10 always), which costs PROF/PBO processes and dominates Table 4 (never-falsified boxes, long sequential-BO runs). ## B. Inconsistencies in the paper and how they are resolved

| ID | Issue (Analysis §7) | Resolution |
|---|---|---|
| **B1** | "100 s at 0.1 Hz = 10 steps", language ⊂ ℝ¹⁰, but φ2 needs samples up to t = 100 s and φ5's □[0,5] is shorter than one sample | D1/D2 below; sensitivity of violation rates to the grid: `results/tables/grid_sensitivity.md` (`analysis/grid_sensitivity.py`) — 10 vs 11 samples barely matters, a 1 s grid changes rates a lot (e.g. φ5 0.55 % → 19 %) |
| **B2** | Eq. (5) is EI in minimisation form, Φ argument uses ŷ(x), ŝ called "variance" | Standard EI for maximisation of Dist (Eq. 4) with the predictive standard deviation |
| **B3** | Eq. (4) falsifier needs Dist > 0; Algs. 1–2 stop at Dist ≥ 0 | D9: candidate needs Dist > 0 (on closed boxes, Dist = 0 includes boundary signals with ρ = 0, which *satisfy* φ; x = 10 exactly is frequent early in CC runs); every candidate is re-checked with RTAMT (ρ < 0) |
| **B4** | UAV rotational dynamics printed as I_x/(I_y−I_z)·θ₂ψ₂ … | Use (I_y−I_z)/I_x (and cyclic), as in the paper's source ref. [47], Sabatino 2015, Eq. 2.22 (checked) |
| **B5** | Table 1 "Satisfaction Ratios" described as the share of trajectories inside the language and a measure of falsification difficulty | Reported both: % satisfying and % violating; the paper's row is shown next to % violating (our interpretation, labelled) |
| **B6** | Table 4 caption mixes modified PROF and sequential BO; its φ4 row duplicates Table 3's SMuRF row | D13 defines both procedures explicitly; we do not try to reproduce the duplicated row |
| **B7** | Control "length 10" formulas use index 10 (□[8,10], ◇[0,10]) while length-30 ones stop at 29 | D17 |

## C. Our decisions for details the paper does not give

All are set in `configs/*.yaml` (where tunable) and recorded in every run's `meta.json`.

| ID | Topic | Decision |
|---|---|---|
| D1 | Output grid | x = y5 − y4 sampled at t = 0, 10, …, 100 s (11 samples) |
| D2 | Seconds → steps | [a, b] s ↦ [⌈a/10⌉, ⌊b/10⌋]; φ5's □[0,5] ↦ □[0,0] |
| D3 | Input parametrisation | u ∈ [0,1]²⁰: u[0:10] throttle, u[10:20] brake, piecewise constant over ten 10-s segments (ARCH uses 'previous' interpolation) |
| D4 | Bounded state space (Thm 2.3) | Not needed: the exact compiler keeps unbounded faces (±∞) |
| D5 | Language monitor | −max_k Dist(x, b_k^{¬φ}) (exact signed distance for satisfying signals; equals robustness) |
| D6 | GP/BO | scikit-learn GP, C·Matérn-5/2 (isotropic) + white noise, normalised targets, MLE every iteration warm-started from the previous fit (1 random restart on the first fit); EI (max form, ξ = 0); acquisition = argmax over 1000 uniform + 1000 local candidates (Gaussian, σ ∈ {0.02, 0.1}, around the top-5 inputs); **identical for proposed methods and baselines**. Isotropic because ARD fits cost 10–30× more (measured) |
| D7 | Starting points | 5 points per trial from seed 1000 + t, shared by every method and every box (paired design, as the paper's "same five starting points") |
| D8 | Iterations | S = BO iterations after the 5 initial samples, including the falsifying one (0 if an initial sample falsifies); parallel methods count lock-step rounds |
| D9 | Falsifier acceptance | Language methods: Dist > 0, then RTAMT ρ < 0 (re-check; with the exact language it always holds). RTAMT methods: ρ < 0. With FindBox languages the re-check can fail (the boxes over-approximate L(¬φ)); the search then continues. Rejected claims are counted in `validation_rejections` (field added 2026-10-18; for older records the tables give exact counts for SMuRF and bounds for PROF). This follows the paper, which validates every falsifier with RTAMT before termination (p.6). Corrected in the Phase 4 audit: an earlier version of this row said the paper did not state this |
| D10 | PBO-RTAMT | j processes (j = boxes of L(¬φ)) share the initial data and differ only by their random streams; stop when any finds ρ < 0 |
| D11 | Timing | `perf_counter_ns` around each monitoring call. T̄_M = mean per call ("single component": one box for PROF/SEQ-BO, all boxes for SMuRF, one RTAMT evaluation for baselines); T̄_T = monitoring time per trial on the critical path. Simulation, GP-fit, acquisition and wall times recorded separately. E1 times monitors interleaved on the same signals |
| D12 | Seeds | Falsification trials 1000 + t (t = 0…19); E1 inputs seed 7; control seed 2000; method streams `SeedSequence([seed, method, spec])` (PROF and modified PROF share streams on purpose) |
| D13 | Table 4 | (a) modified PROF: PROF continued until every box is falsified or 200 rounds → S_min, S_max (unfalsified boxes count as 200); (b) sequential BO: random box order, fresh BO per box from the trial's 5 initial signals, ≤ 200 iterations per box |
| D14 | UAV parameters | m = 0.5 kg, I_x = I_y = 5·10⁻³, I_z = 9·10⁻³ kg m², g = 9.81 (typical small quadrotor; the thesis text gives no values) |
| D15 | Tracker | cascaded PD: x-position PD + reference-velocity feed-forward → pitch command (≤ 35°), altitude hold, roll/yaw held at 0, attitude PD (k_p 400, k_d 40), thrust ≤ 2.5 mg, torques ≤ 0.5 N m; RK4, dt = 0.01 s; planar integration is exact (tested) |
| D16 | LangControl | Sample = uniform box then uniform point; Projection = Euclidean projection onto the nearest box (LCW) or own box (LCP); M = 500, K = 10 |
| D17 | Control signal lengths | length-10 formulas on 11 samples (index 0…10); length-30 on 30 samples |
| D18 | Statistics | mean ± 95 % t-CI (reference project's method), medians, ratio of means and geometric means (unrounded), paired Wilcoxon on per-trial iterations; S̄/T̄_T over falsified trials, FR reported separately |
| D19 | Signal domains | [0, 20] for length-10 and [0, 100] for length-30 control formulas |
| D20 | Control time base | one sample per second; drone starts at rest at x1 = 0 |
| D21 | LCP processes | at most 64 boxes (seeded random subset) per LCP run; φ1/φ5 languages are exact products of interval unions (2¹¹ and 2³⁰ boxes) |
| D22 | E6 robustness-BO control baseline | decision variable = reference signal x_ref ∈ domain^n (the variable LangControl manipulates), normalised to [0,1]^n; objective = RTAMT robustness of **φ ∧ □(x ∈ domain)** of the tracked trajectory; success when it is ≥ 0, which equals LangControl's membership test in the domain-bounded language (tested). A first run used plain ρ_φ, whose success test is more lenient (trajectories leaving the domain counted as successes; e.g. φ3: 81.5 % vs 40.4 % of random references); it is kept as `results/raw/control_bo/main_superseded_v1/` with an explanation and is not used. One iteration = one Track call, initial samples included |
| D23 | E6 budget and BO | 5 random initial references + ≤ 200 BO iterations (205 Track calls); GP/EI/acquisition as D6; compared with LCW *within the same 205-call budget* (LCW itself ran up to 5,511 calls in E5) |
| D24 | E6 scale | 50 replications per objective (seeds 3000 + rep); the paper's "preliminary experiments" give no count |
| D25 | FindBox settings (paper: none stated) | Signal space and sampling are FindBox inputs. Two variants (`configs/findbox.yaml`): **default** = FindBox as shipped (its `Box()` default borders give the integer grid 0..100; its `FindBox()` samples 1000 points with `random.randint`); **besteffort** = FindBox's own continuous sampler `sampleC` on [0, 70] (≈ the reachable range of y5−y4, 7.6–68.8 in E1), 1000 points. Both: 11 samples (D1), Python `random` seeded with 0, oracle = robustness of ¬φ ∧ □(x within bounds) (FindBox's README pattern), computed by our scalar robustness, which equals RTAMT dense-time exactly on these formulas (`tests/test_findbox.py`) and is 2–4× faster. FindBox's final self-check samples reconstructed boxes with `random.randint`, which rejects float borders on Python ≥ 3.12; we use its `sampleC` there. Consequence of integer sampling: violation sets of width < 1 (φ4 needs 32 < x < 33) are never sampled in the default variant. **Best-effort φ1 was not completed.** It was stopped after 5.5 h, because FindBox's `recon` step slows down sharply with distinct floating-point corner coordinates (26/72/542 s for 50/100/200 points, `results/logs/findbox_recon_scaling.log`), which extrapolates to 16–20 h or more. See `results/raw/findbox/main/INCOMPLETE.md`. The other 9 languages are complete |
| D26 | Authors' tracker in FindBox (`ss_tracker`: LQR on the paper's quadrotor model, m = 1.0, I_x = I_y = 8.1·10⁻³, I_z = 14.2·10⁻³) | **Not used for Table 5.** It runs on Python 3.14 but costs 0.66–2.3 s per Track call (E5 needs 10⁵–10⁷ calls), and on a random reference in [0, 20] its output drifted to −7 while the reference stayed at +10…+18; with `time=29` it ended at 3.2 when tracking toward 100. It looks like prototype code, and nothing ties it to the paper's Table 5. It confirms B4 (it uses (I_y − I_z)/I_x) |

## D. Not reproduced

- **E6** (robustness-BO control baseline, "3–7× more iterations"): the paper gives no data, so there is nothing to
  reproduce numerically; we test the claim itself at reduced scale (D22–D24) as new evidence.
- **Figures 1–4** (illustrations): not reproduced.
- **Exact numbers** of Tables 1–5: impossible without the authors' seeds, starting points, BO settings, FindBox boxes and hardware. We compare FR, iteration distributions and speedup ratios.
- **Table 5 values**: depend on the unspecified tracker and LangControl settings → our control results are a re-implementation (level L3), comparable only in trends.
