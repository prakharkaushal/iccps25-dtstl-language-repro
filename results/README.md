# Results layout and record schema

```
results/raw/<experiment>/<run-id>/meta.json      config, created, sessions[] (argv, source sha256, environment, start/finish)
results/raw/<experiment>/<run-id>/records.jsonl  one JSON object per finished unit of work (append-only, resumable)
results/raw/e1_monitoring/<run-id>/signals.npz   E1 inputs (N x 20) and simulated signals x (N x 11)
results/raw/findbox/<run-id>/<variant>_<spec>.json   FindBox boxes of L(not phi) (BoxUnion JSON: lo, hi)
results/logs/                                     console logs of long runs
results/matlab/                                   Simulink comparison (scripts/cc_matlab_compare.py, scripts/matlab/run_cc_reference.m):
                                                  cc_inputs.csv (200 x 20, seed 99), cc_outputs_python.csv (our port),
                                                  cc_outputs_simulink*.csv (Simulink; 5 cars x 11 samples, car-major),
                                                  falsifiers_<run>_{inputs,index,simulink}.csv (falsifiers of a falsification
                                                  run re-simulated on Simulink), *_meta.txt (MATLAB version, solver, timing)
results/tables/                                   tables (.md) and plots (.png) generated by analysis/ and scripts/
results/figures/                                  illustrations for the paper's Figs. 1-4 (analysis/plot_figures.py)
```
Run ids: `main` = full run with the config's trial/replication counts; `pilot` = reduced run used to validate the
pipeline and size the full runs (tables built from it say **PILOT**); `findbox_default`, `findbox_besteffort` =
E2/E3 with FindBox languages instead of the exact ones (`configs/falsification_findbox_*.yaml`).
A run directory with `SUPERSEDED.md` is kept for provenance only (the file says why and what replaces it).

## E1 `e1_monitoring` — one record per requirement
`spec`, `paper_text`, `formula_steps` (discretised formula), `n`, `n_boxes_neg` (boxes of L(¬φ)),
`language_compile_ms`, `value_agreement_pct`, `sign_only_agreement_pct`, `complete_disagreement_pct`,
`satisfying_pct` (ρ ≥ 0), `violating_pct` (ρ < 0), `rho_zero_pct`, mean ms per call of `rtamt_discrete_ms`,
`rtamt_dense_ms`, `language_ms` (all boxes), `one_box_ms`, `rtamt_discrete_1s_grid_ms`,
`rtamt_discrete_0.1s_grid_ms` (extra, longer traces), `rtamt_dense_vs_discrete_max_abs_diff`,
`ours_vs_rtamt_max_abs_diff`.

## E2/E3 `falsification` and E4 `table4` — one record per (spec, trial, method)
Identity: `spec`, `trial`, `seed`, `method` (PROF, PBO-RTAMT, SMuRF, SBO-RTAMT, PROF-all, SEQ-BO), `n_boxes`.
Outcome: `falsified`, `iterations` (D8), `stop_reason`, and if falsified `falsifier_u` (20 inputs),
`falsifier_x` (11 samples), `falsifier_rho` (RTAMT, < 0), `falsifier_box`.
Costs (ms unless noted): `T_T_ms` (monitoring on the critical path), `T_M_ms` (mean per monitoring call),
`monitor_calls`, `monitor_ms_total`, `monitor_ms_critical`, `n_sims`, `sim_ms`, `n_gp_fits`, `gp_ms`, `acq_ms`,
`validation_calls` (RTAMT re-checks of language claims, D9), `validation_rejections` (re-checks with ρ ≥ 0; present in
run `findbox_besteffort` and later runs (added on 2026-10-18, before that run started); for older records
`analysis/make_tables.py` derives it: exact for SMuRF, bounds for PROF), `validation_ms`, `wall_s` (seconds).
PROF: `best_dist_per_box`. PROF-all: `S_min`, `S_max`, `per_box_iterations`, `never_falsified_boxes`.
SEQ-BO: `boxes_tried`, `box_order`.
Not-applicable runs (empty language, e.g. FindBox found no box): `stop_reason` = "not-applicable: empty language",
`iterations` = null, `falsified` = false.

## E5 `control` — one record per (spec, variant)
`spec`, `variant` (LCW/LCP), `reps`, `iterations` (per replication, −1 = no feasible signal within M, K),
`successes`, `failures`, `P_bar_success`, `P_median_success`, `P_max_success`, `n_tracks` (Track calls, all
processes), `n_processes`, `n_boxes_language`, `language_repr`, `M`, `K`, `max_processes`, `seed`, `wall_s`.

## E6 `control_bo` — one record per (spec, replication)
`spec`, `rep`, `seed`, `n` (signal length), `domain`, `success` (robustness of φ ∧ □(domain) ≥ 0 within the
budget, D22), `iterations` (BO iterations after the 5 initial references; 0 if an initial one succeeds),
`best_rho`, `track_ms`, `gp_ms`, `wall_s` (seconds).

## FindBox `findbox` — one record per (variant, spec)
`variant`, `spec`, `bounds` (signal space [lo, hi]^n), `n`, `sampler` (integer / continuous), `seed`,
`oracle_impl`, `n_samples` (points sampled), `samples_inside_language` (oracle > 0), `n_boxes`,
`oracle_calls_build`, `walk_s`, `total_s` (seconds), FindBox's own final check: `check_box_points` /
`check_over_bad_points` (points sampled in the boxes / of those outside L(¬φ)), `check_language_points` /
`check_under_bad_points` (sampled points of L(¬φ) / of those not covered), `corner_points`,
`findbox_stdout_chars`, `boxes_file` (absolute path in run `main`; file name relative to the run directory in
later runs).
